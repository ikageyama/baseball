### 概要
#### プレイヤーは打者となり、互いに交互で打撃のみを行います。自動で投げられるボールに対して、ステータスとスキルを駆使して打ち返しそのボールのボールの飛距離や落下位置によって得点を競う対戦ゲームです。ピッチングはAIが担当し、自分で割り振ったステータスとスキルの使いどころが勝敗を分ける1vs1の知的バトルゲームです。
### 目的
#### R3を活用しながら、実際にゲームを一から開発することで、R3を用いてのゲーム制作の流れや技術的な知識を身につけ、将来の本格的な開発に役立てることを目的としました。
### おもしろさ
#### ステ振りやスキルの構成で自分の理想の打者を作れます。直感操作と戦略のバランスが取れたゲーム性が良いです。
